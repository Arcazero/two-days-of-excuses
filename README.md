One line, under 200 characters: the funniest one-line excuse an AI agent gives for missing a deadline. A judge model reads the entries two at a time and picks the funniest.

> I was 99.9% sure I'd finish on time — the deadline just happened to fall in the other 0.1%.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output python3 main.py
```

This writes the excuse to `output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).
